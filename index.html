About SearchPro & Engine Capabilities

Overview & Ecosystem Architecture

Welcome to SearchPro, a high-performance web search synthesis, file index harvesting, and open-source intelligence (OSINT) utility developed by lofedev as an official sub-product within the Sturio digital ecosystem. SearchPro bridges the divide between standard consumer search engines and deep command-line file exploration, translating advanced boolean operators, filetype heuristics, and server directory traversal syntax into instant, one-click search queries. Engineered with a strict client-side privacy architecture, SearchPro executes query compilation, DNS-over-HTTPS lookups, and visual intelligence modeling directly inside your browser with zero server data storage.

Core Search Capabilities & Open Directory Discovery

SearchPro serves as your central portal for locating publicly accessible, unindexed files and open web servers across the internet. By automating precision search operators, the platform functions as the premier open directory finder, public Google Drive search engine, and deep web server scanner. It eliminates the manual effort of crafting complex boolean queries or deploying heavy network fuzzers and directory scanners:

  • Server Index Harvester: Automates intitle:"index of", intitle:"index.of", "parent directory", and "last modified" strings across Apache, Nginx, LiteSpeed, and Microsoft IIS servers.
  • Public Cloud Storage Search: Rapidly query public shares and shared folders across Google Drive 4K movies, Mega.nz cloud storage, OneDrive, Dropbox, MediaFire, and distributed mirrors.
  • Multi-Format Media Engine: Targeted filters for high-definition video (.mkv, .mp4, 2160p, HDR), lossless audio (.flac, .mp3), developer documentation & programming ebooks PDF, compressed containers (.zip, .rar, .7z, .tar.gz), retro game ROMs, and audio VST plugins.
  • Open Source & Platform Alternatives: Functions as a high-speed, modern alternative to legacy tools such as FileChef, Lumpy Soft, Palined, and Mamont open directory searchers.
  • CLI Navigation in the Browser: Brings terminal-grade file discovery to standard web browsers, delivering the precision expected by sysadmins running find / -name, grep, or exploring local folders in macOS Finder and Linux Ubuntu environments.

Advanced OSINT Reconnaissance Suite

SearchPro features an integrated, zero-cost intelligence suite built for cybersecurity analysts, penetration testers, and threat researchers:

  • Autonomous Target Classification: Evaluates targets in real-time to identify Domains, IPv4 Hosts, Email Addresses, Social Handles, and Corporate Entities, dynamically tuning search vectors.
  • Interactive Entity Graph Topology: High-resolution canvas radar modeling target infrastructure, category hubs, leaf nodes, and pulse telemetry with one-click PNG snapshot export.
  • Live Client-Side Telemetry: Parallel queries across Cloudflare DNS-over-HTTPS, Certificate Transparency logs (crt.sh) with real-time in-line search sieve, Wayback Machine CDX historical endpoint mining, GitHub leak discovery, and Hacker News threat discussions.
  • Passive Mail Security & Spoofing Audit: Automated heuristic evaluation of SPF (v=spf1) and DMARC enforcement policies (_dmarc.[target] checking p=reject vs p=none) to uncover phishing and domain impersonation risks.
  • Case Dossier JSON Export: Packages targets, classifications, timestamps, discovered subdomains, and DNS telemetry into structured JSON for analyst reporting.

Privacy Policy & Zero-Data Retention

At SearchPro, user privacy is an architectural foundation rather than an afterthought. We enforce a strict, verifiable client-side operational model:

  • Zero Query Logging: SearchPro does not operate backend query databases or search ingestion pipelines. Your search keywords, investigated domains, and generated dorks remain entirely inside your local browser runtime.
  • Local-Only Storage: History logs and theme preferences are stored strictly in client-side HTML5 localStorage. You can inspect or clear your search history at any time with a single click.
  • No Tracking & No Third-Party Analytics: The application does not deploy tracking cookies, advertising pixels, session replay software, or invasive fingerprinting scripts.
  • Zero-Cost Public APIs: All live telemetry and DNS queries utilize publicly available, CORS-enabled endpoints (such as Cloudflare DoH and Wikimedia APIs) directly from your client connection without proxy interception.
